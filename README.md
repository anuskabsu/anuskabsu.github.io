# Anuska's portfolio

A lightweight, responsive portfolio built for GitHub Pages. All editable copy, projects, links, awards, publications, travel destinations, and social channels live in [`content.js`](./content.js).

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

For a site at `https://YOUR-USERNAME.github.io`, name the repository `YOUR-USERNAME.github.io`.

## Add your résumé

Upload your resume PDF to this repository (for example, `assets/resume.pdf`) and set `resume: "assets/resume.pdf"` in `content.js`. Or use a direct hosted PDF URL.
